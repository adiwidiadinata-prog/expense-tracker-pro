# 🚀 Quick Start

## 1. Coba Langsung (Tanpa Setup)
Buka file **`expense-tracker-pro.html`** di browser
→ Klik "🎮 Mode Demo"

## 2. Deploy ke Firebase (Production)
1. Buka https://console.firebase.google.com
2. Buat project baru
3. Copy config ke aplikasi
4. Deploy dengan Firebase CLI

📖 Lihat **README.md** untuk panduan lengkap
